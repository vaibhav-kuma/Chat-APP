# Cybersecurity Learning Documentation

## Overview
This directory contains documentation, guides, and learning resources for various cybersecurity topics.

## Contents
- Learning paths for different security domains
- Cheatsheets for common tools and techniques
- Reference materials and glossary
- Recommended books, courses, and online resources

## Getting Started
1. Review the learning paths to determine your current skill level
2. Follow the recommended progression for your chosen security domain
3. Complete the practical exercises in the corresponding directories
4. Document your findings and learnings

## Resources
- [OWASP](https://owasp.org/) - Web security resources
- [HackTheBox](https://www.hackthebox.eu/) - Hands-on cybersecurity training
- [TryHackMe](https://tryhackme.com/) - Learn cybersecurity through hands-on exercises
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) - Web security learning materials
