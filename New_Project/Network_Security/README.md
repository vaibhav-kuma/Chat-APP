# Network Security Learning Path

## Overview
This directory focuses on network security concepts, protocols, and penetration testing methodologies.

## Topics Covered
- Network Fundamentals (OSI Model, TCP/IP)
- Network Scanning and Enumeration
- Packet Analysis
- Firewall and IDS/IPS
- VPN Security
- Wireless Network Security
- Network Protocol Vulnerabilities

## Learning Resources
- [CompTIA Network+ Certification](https://www.comptia.org/certifications/network)
- [Wireshark Documentation](https://www.wireshark.org/docs/)
- [Practical Packet Analysis](https://nostarch.com/packet3)

## Practice Environments
- GNS3 Network Simulations
- Packet Tracer Labs
- Vulnhub Network-focused VMs

## Tools
- Wireshark
- Nmap
- Netcat
- tcpdump
- Snort

## Getting Started
1. Review network fundamentals and the OSI model
2. Practice basic network scanning with Nmap
3. Learn packet analysis with Wireshark
4. Set up a small test network for security testing
