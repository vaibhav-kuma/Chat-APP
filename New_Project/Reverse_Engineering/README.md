# Reverse Engineering Learning Path

## Overview
This directory focuses on reverse engineering concepts, tools, and techniques for analyzing software.

## Topics Covered
- Assembly Language Basics
- Binary File Formats (ELF, PE)
- Disassembly and Decompilation
- Dynamic Analysis
- Static Analysis
- Anti-Debugging Techniques
- Malware Analysis Fundamentals

## Learning Resources
- [Practical Malware Analysis](https://nostarch.com/malware)
- [Reverse Engineering for Beginners](https://beginners.re/)
- [x86 Assembly Guide](https://www.cs.virginia.edu/~evans/cs216/guides/x86.html)

## Practice Exercises
- Crackme Challenges
- Reverse Engineering CTF Challenges
- Simple Program Analysis

## Tools
- Ghidra
- IDA Pro/Free
- Radare2
- x64dbg/OllyDbg
- Binary Ninja

## Getting Started
1. Learn basic assembly language concepts
2. Practice with simple crackme challenges
3. Understand how to use disassemblers and debuggers
4. Progress to more complex reverse engineering tasks
