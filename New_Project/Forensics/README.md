# Digital Forensics Learning Path

## Overview
This directory focuses on digital forensics concepts, techniques, and tools for investigating security incidents.

## Topics Covered
- File System Analysis
- Memory Forensics
- Network Forensics
- Disk Imaging
- Log Analysis
- Artifact Recovery
- Timeline Analysis
- Mobile Device Forensics

## Learning Resources
- [SANS FOR500: Windows Forensic Analysis](https://www.sans.org/cyber-security-courses/windows-forensic-analysis/)
- [Digital Forensics and Incident Response](https://www.packtpub.com/product/digital-forensics-and-incident-response-second-edition/9781803231303)
- [Practical Forensic Imaging](https://nostarch.com/forensicimaging)

## Practice Exercises
- Forensic CTF Challenges
- Memory Dump Analysis
- Disk Image Examination

## Tools
- Autopsy/Sleuth Kit
- Volatility
- FTK Imager
- Wireshark
- ExifTool

## Getting Started
1. Learn basic forensic principles and methodologies
2. Practice with sample disk images and memory dumps
3. Understand chain of custody and evidence handling
4. Document findings in forensic reports
